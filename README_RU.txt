Herobrine Co-op — исходный проект дополнения
Minecraft 1.20.1 / Forge 47.4.22 / Java 17

Что добавляет:
- Кнопку «Herobrine Co-op» в главном меню и «Herobrine Co-op / LAN» в меню паузы.
- Экран с действиями «Создать LAN-сервер» и «Подключиться к другу».
- Подключение по введённому адресу IP:порт через штатный сетевой экран Minecraft.

Важно:
- Это клиентское меню-расширение. Оно НЕ переписывает синхронизацию хоррор-событий Herobrine.
- Чтобы открыть LAN, сначала зайдите в одиночный мир, затем используйте ESC → Открыть для сети. Кнопка в главном меню не может открыть мир, которого ещё нет.
- В уже открытом мире действие «Создать LAN-сервер» из экрана дополнения недоступно; используйте штатное меню ESC → Открыть для сети.
- Для друга укажите локальный IPv4 хоста и порт, который Minecraft покажет после открытия LAN. Оба игрока должны иметь одинаковые версии Minecraft, Forge, Herobrine и Modern Beta.
- Это исходники проекта, а не готовый проверенный JAR. Для сборки нужен ForgeGradle и доступ к репозиториям Maven.

Сборка:
1. Установить JDK 17.
2. Открыть папку проекта в терминале.
3. Выполнить: gradle build
4. JAR появится в build/libs/HerobrineCoop-1.0.0.jar

Если ForgeGradle сообщит об ошибке API, потребуется поправить исходники под конкретный Forge MDK.
